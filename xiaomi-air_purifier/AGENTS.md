# Xiaomi Air Purifier

A Home Assistant device integration for a Xiaomi Air Purifier

## Device details

Device property and action schema can be found in a [json file](./schema/xiaomi.airp.mb5.json) in the schema directory. This file is generated by the XiaomiMiio.Cli utility.

## Functionality implemented

### Integration setup

- On setup of a new instance the integration should request an IP and a token to be provided by the user.
- Multiple instances of the device might be added to HA (e.g. different air purifiers in different rooms - persistence of ip/token should take this into account)

### Operational functionality

- Device on/off
- Fan level
- Screen on/off
- Anion on/off
- UV on/off

### Information display and charting

#### Environmental parameters

- Temperature in celcius units
- Relative humidity
- PM1
- PM2.5
- PM10

#### Operational parameters

- Fan speed in RPM
- Filter life level
